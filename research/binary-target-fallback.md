# Try a second binary target after a missed consequence

The [partition preparation study](partition-preparation.md) saved a 125-variable
branch with 57 binary and 263 ternary clauses. It took nine ordinary expansions.
This investigation asks which structure the current bounded recognizer misses,
before adding more preprocessing or changing the native proof rules.

## Existing policies and the specific miss

Fresh solvers restore the exact saved pre-branch state. The original total-frequency
single target takes 24 expansions; the binary-frequency single target takes nine;
the existing four total-frequency targets take 19; the existing cover-partial
policy takes eleven. Every resulting certificate is checked and retained. These
are exploratory exposed-case counts, not held-out performance evidence.

A complete diagnostic binary reachability census finds four forced values at the
root. The binary-frequency policy already chooses a useful one: falsifying literal
50 propagates three further assignments, covering the other forced binary values.
Simply increasing the whole-cover search budget does not reveal a full false-clause
cover there. The existing stronger root choice is retained.

The miss appears after that restriction and propagation. In the resulting
121-variable residual, the highest binary-frequency variable (42) is not forced,
but the second-ranked variable (62) is. A checked path from -62 to 62 certifies
that 62 must be true. The first-target recognizer returns no consequence, then
ordinary search splits a different variable. This is a missed literal-recognition
opportunity, not an unresolved whole-input decision: the baseline already solves
all of the exposed branch.

## Bounded shared discovery

The optional policy keeps the existing whole-cover priority, binary model and
implication graph. Only when the first binary-frequency target misses does it
try the second. Completed path searches, including completed misses, remain
reusable. A cover-budget stop is not stored as proof that no path exists.
The surviving binary model excludes one polarity for each target; discovery
searches the potentially refutable opposite polarity.

For each binary clause `(a ∨ b)`, the graph contains `¬a -> b` and `¬b -> a`.
A path `l -> ¬l` proves that the binary subset, hence the complete source CNF,
excludes `l`. The existing source-indexed path checker validates every edge.
The existing compiler produces the excluded cofactor's native unit certificate;
only the surviving cofactor is searched. SAT still requires a checked source
model, and UNSAT still requires checked negative children. This uses established
binary-implication reasoning, with no new proof format or trusted inference.

With `L` source literal occurrences and a binary graph of `V_b` literal vertices
and `E_b` edges, this bounded recognizer charges source scanning, target sorting
and at most eight cover roots plus two targeted reachability roots. A simple
comparison/RAM bound, assuming expected constant-time dictionary operations, is
`O(L + V_b log V_b + 10(V_b + E_b))`; integer widths and
allocation are separate. Retained graph/path state is input-dependent. Only one
additional target is admitted relative to the prior binary-frequency policy.
The bound covers recognition, not recursive acquisition, checking, persistence
or the number of novel residuals generated by arbitrary SAT.

The first prototype recognizes the missed consequence but still uses nine
expansions on the exposed branch. A different forced value can change the
continuation without shrinking the total proof graph. Performance therefore
requires a matched workload comparison; recognition success alone is insufficient.

## Frozen comparison

After eight development tests, the policy and comparison inputs are frozen.
Binary-frequency one-target and two-target arms use the same shared partition
preparation on whole queries. Six preceding edits become controls. Six new
fixed-seed nearby edits have roots absent from the prior cumulative union. Three
exposed branch variants (original, one variable's sign flip and global complement)
share the captured pre-branch seed. The new branch trials allow 256 ordinary
expansions, versus 247 left in the original call; the exposed policies use fewer.

Thirty-six separate serial workers run in two opposite orders, yielding 60
attempts. Recognition, misses, checking, publication, warm use, persistence and
cold replay remain charged. Profiling and cumulative audits follow timing. Each
trial is checked independently; changed native payloads are retained rather than
requiring artificial proof-shape identity. Candidate donors/maps and earlier
acquisition remain supplied/sunk. This is a local comparison, not an external
SAT holdout or a uniformly efficient partition of all CNFs.

## Results and the probe boundary

All fifteen targets finish as UNSAT under both policies. A bounded second target
recognizes an additional consequence; it adds no whole-input decision coverage.
The table sums the separate case streams and averages the two serial orders.

| Measurement | Controls: one target | Controls: two targets | New edits: one target | New edits: two targets |
| --- | ---: | ---: | ---: | ---: |
| Ordinary expansions | 58 | 58 | 69 | 60 |
| Query seconds | 0.17071 | 0.17265 | 0.19327 | 0.17724 |
| Complete measured worker seconds | 24.03823 | 23.86617 | 24.44422 | 24.29460 |
| New native key/payload bytes | 522,190 | 532,191 | 509,786 | 505,227 |
| Endpoint checked-object bytes | 3,258,999 | 3,298,674 | 3,432,343 | 3,196,877 |
| Compressed deltas plus raw sidecars | 152,812 | 152,810 | 151,881 | 150,562 |

New-edit query time improves **8.29%**, with both orders improving; complete
worker time improves **0.61%**, also in both orders. These two local repetitions
do not establish a broad speedup. Complete worker time includes prefix restoration,
reconstruction and full cold auditing, which dominate acquisition. Endpoint object
space falls **6.86%** on new edits, but these are summed end states of separate
workers, not a peak RAM bound. New native payload falls **0.89%**. Raw sidecars
remain 103,542 bytes. Summed measured worker RSS peaks increase slightly and include
loaded archives and accounting allocations; no process-memory saving is established.

Controls regress **1.14%** in query time in both orders and retain **1.92%** more
native payload. The exposed branch and both sign variants still take nine
expansions. Original/one-variable-flip query means change by -0.43%/+0.23%, with
mixed paired signs. The complemented branch regresses **3.27%**, with both orders
worse. All three retain approximately **8.4–8.5%** more native payload. On new
edits the second target is tried sixteen times and succeeds twice; on controls it
is tried fourteen times and succeeds once. A valid extra deduction can still
produce a larger certificate and slower continuation. General defaults are unchanged.

The expansion reduction is concentrated in new case 61's replacement. The baseline
uses eight probe expansions and nine after restart, totaling **17**. The second
target finishes within the probe in **8**. A separate posthoc ablation replays the
earlier deletion, then acquires the replacement directly without the initial
stop or support preparation. Direct acquisition takes **11 versus 8** expansions.
Thus the wrapped 17-to-8 change includes six extra baseline expansions in the
probe/fallback workflow relative to direct acquisition, alongside a three-expansion
direct search difference. This is a net count decomposition, not a count of
identical repeated frames, a timing attribution or a general bound. Retained hints
can also change the subsequent search.
Some completed probe proofs are reused; the unfinished search frames are lost.
All direct-ablation proof bytes already occur in the independently audited frozen
trial deltas. `probe-boundary.json` binds these sources, results and record IDs.

## Next gap and preserved state

The [earlier probe study](probed-support-partition.md) already identified incomplete
continuation loss. The boundary ablation makes it measurable on another exact
case. **Next, investigate retaining the unfinished native continuation at the
probe budget**, then resuming it if routing chooses native fallback. This can
avoid rebuilding work across several SAT categories without requiring a larger
set of consequence probes. Bind a continuation to its source, solver policy and
state; keep incomplete frames separate from checked answer authority. Charge
retained frame data, publication, invalidation and cold reconstruction. Compare
resumption with restart and direct acquisition on both satisfiable and
unsatisfiable sources, budget stops and edits. If a partition is chosen instead,
retained native frames may have no value and must not become unbounded storage.

The dominant new query remains case 31's deletion: **83.67/84.72 ms** under
one/two targets, with the same 29 expansions. `next-target.json` binds both
instrumented reproductions and the exact persistent pre-query state. Every
reproduced proof payload, partition and expansion count matches the frozen trial.
A separate audit records the source-indexed path that the first target misses.
Native normalization calls rise 107 -> 109 and publications 29 -> 30; propagation
calls fall 24 -> 23. These profiles locate work, not speedups. Better consequence
utility, sidecar compression and automatic donor/map discovery remain open.

Resume `experiments/results/cnf-binary-interactions/checkpoint.json`. The cumulative
archive has **75,677 native records**, adding 169 distinct keys and preserving
22 alternative-payload observations in trial artifacts. Both readers recheck the
native archive and **242** accumulated partition records (226 prior plus 16 new).
All previous extension tables are unchanged. All **1,446 full tests** and
**154 focused tests** pass; the full suite emits its existing unclosed-SQLite
warnings, while the focused suite emits none. The final manifest binds source,
experiment, test and manuscript checks. This is local acquisition evidence, with
supplied donors/maps and sunk earlier acquisition; uniform discovery, source
composition and unrestricted SAT resource bounds remain unresolved.
