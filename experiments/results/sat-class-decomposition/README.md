# Tractable classes and their interaction

Research checkpoint, 8 November 2026. No production solver, Lean or manuscript
change. [The analysis](../../../research/arbitrary-sat-expansion.md) records the
literature, the arbitrary-SAT scope and the revised implementation priorities.

`diagnostic.json` is generated by
`experiments/analyze_sat_class_decomposition.py`. It checks an elementary
indicator construction that replaces each variable x by two indicators p_x/n_x.
One component is positive dual-Horn CNF; the other is negative Horn/2-CNF.
Their conjunction enforces complementary indicators and has exactly the models
of the original formula under the obvious correspondence. For nonempty clauses,
each component is satisfiable by itself; deciding their compatibility still
encodes arbitrary SAT. This is an explanatory construction, not a claimed new
reduction or an algorithmic lower bound.

The diagnostic exhaustively checks the correspondence for every extended
assignment on **460 formulas**, including all 256 subsets of the eight nonempty,
nontautological clauses over two variables, four edge cases and 200 seeded
three-variable cases. Outcomes are **224 SAT / 236 UNSAT**. Empty clauses,
contradictory units, an empty formula and a tautology are included.

It also instantiates the introductory example from
[Gaspers et al., AAAI 2014](https://www.cs.ox.ac.uk/standa.zivny/publications/gmosz14aaai-preprint.pdf).
Setting one variable yields a Horn residual in one branch and a 2-CNF residual
in the other. At example size four, exhaustive homogeneous backdoor searches
through size two find neither a Horn nor a 2-CNF backdoor, whereas the mixed
portfolio finds a size-one backdoor. These findings reproduce a published
mechanism. The retained failed searches are bounded failures, not evidence of
nonexistence at larger sizes.

The recognizers check explicit syntax; they do not infer arbitrary semantic
equivalence to a tractable formula. The detector enumerates subsets and their
assignments, so it is not the paper's efficient parameterized detector. It
records candidate and branch counts. `source_literal_visits` counts original
literal payload once per attempted branch, not all literal inspections, class
checks or machine instructions. No timing or performance improvement is claimed.
The diagnostic does not use or change the main solver archive.

Reproduce in a new file:

```sh
python3 experiments/analyze_sat_class_decomposition.py --output /tmp/sat-class-decomposition-new.json
```
