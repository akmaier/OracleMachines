# Scheduling pilot, excluded from reported timings

This first matched run began before affine archive adoption had completed.
All raw records, frozen inputs and run databases are retained, but **none of its
timings is used for the reported comparison**. The sibling `matched/` directory
repeats the identical inputs and binary after adoption finishes, without builds,
tests or archive adoption running alongside the timed experiment. Directory names
changed after the pilot; database paths recorded in its reports remain valid.
